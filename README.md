# ESP32 Shed Environmental Monitor

A Wi-Fi-connected environmental monitoring system built with an ESP32 and SHT31 sensor to monitor temperature and humidity inside a workshop/shed.

## Features

- Real-time temperature monitoring
- Relative humidity monitoring
- Wi-Fi signal strength measurement
- Device online/status indicator
- Embedded web dashboard accessible over the local network
- Programmed in C++ using the Arduino IDE

## Hardware

- ESP32 development board
- SHT31 temperature/humidity sensor
- Breadboard/prototyping hardware
- 5 V USB power supply

## Software

- C++
- Arduino IDE
- HTML/CSS
- ESP32 Wi-Fi libraries
- SHT31 sensor library

## How It Works

The ESP32 reads temperature and humidity values from the SHT31 sensor. It connects to the local Wi-Fi network and hosts a webpage that displays the current sensor readings, Wi-Fi signal strength, and system status.

## Project Goals

This project was created to monitor environmental conditions in my workshop while gaining hands-on experience with:

- Embedded programming
- Sensor interfacing
- Wi-Fi networking
- Web interfaces
- Electronics prototyping
- Hardware/software integration
